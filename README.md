# Xiao AI Studio 3.6.5 · AI 团队素材版

在 3.6 AI 配音版基础上，为「AI 团队」新增图片和视频素材上传。

- 图片最多 20 张
- 视频最多 5 个（MP4 / MOV / WebM）
- 视频在浏览器本机提取代表画面，不上传完整视频
- AI 团队直接生成小红书内容、标签、封面文字和短视频脚本
- 保留多图图片工作室、内容工厂、视频剪辑和 AI 配音


## 3.6.5 新增
- 脚本自动拆分分镜
- 每个镜头生成 AI 图片
- 每个镜头创建 AI 视频任务并显示进度
- 支持 9:16、16:9 与方形画面设置


## 3.6.5 新增
- 脚本一键生成 AI 配音与 SRT 字幕
- 配音播放时实时预览字幕
- 上传视频后可在浏览器本地合成带配音与烧录字幕的成片


## 3.6.5 新增
- 批量内容流水线支持最多100张图片
- 支持拖拽、预览、单张删除和一键清空
- AI读取前20张代表图片并结合全部文件名进行分组
- 每篇内容明确对应图片编号或文件名


## 3.6.5 新增
- 小红书 / 抖音热点中心
- 使用 OpenAI Web Search 查找近期公开热点
- 自动生成选题、标题、开头钩子、建议素材和发布顺序
