# 小翠 AI 工作台 v2

这是一个不需要安装、也不需要 API Key 的静态网页工作台。

## 功能
- 选题助手
- 小红书文案
- TikTok 英文脚本
- 餐馆宣传
- 英国生活
- 英国驾照
- 狗狗日常
- 数据分析
- 发布计划

## 使用
直接双击 `index.html`。

## 上传 GitHub
把 `index.html`、`style.css`、`app.js`、`README.md` 上传到仓库根目录。

## 发布到 Cloudflare Pages
连接 GitHub 仓库，Framework preset 选择 None，Build command 留空，Output directory 留空或填写 `/`。

当前版本不会调用 OpenAI API，也不会产生 API 费用。
